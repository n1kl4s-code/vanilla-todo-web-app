# You have TODO it! - your go-to todo app in the browser
**You have TODO it!** is a simple todo app created with HTML, CSS and JavaScript.

# Features
**You have TODO it!** supports the four CRUD operations:

### Create ✏️
**You have TODO it!** makes it super easy to create todos so you never have to worry about forgetting anything important ever again.
Simply click the **Add new TODO...** button and create as many todos as you want.
### Read 📖
**You have TODO it!** can't read your mind (yet), but it is able to read every todo you ever created from the **localStorage** of your browser.
This feature allows you to track your progress whereever you are - just open the app and see for yourself.
### Update ✨
With **You have TODO it!**, updating your created todos is made fairly simple...whether you check the checkbox to mark a todo as done or just update your completed todos to keep your todo list concise...
**You have TODO it** supports it all with just **one** click!
### Delete 🗑️
Let's say you don't want to see a todo in your list anymore, because you are afraid of others seeing that you just created a todo to remind yourself of brushing your teeth...fear no more, because **You have TODO it!** allows you to delete any todo you ever created...so nobody will ever see anything you don't want them to see.
